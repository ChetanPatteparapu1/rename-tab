Privacy

  • No network requests. No servers, no analytics.
  • It reads and writes the tab title, never page content.
  • Chrome lists it as able to read every site, because putting a name back after a reload means running on the page that loaded.
  • Nothing is written to disk. Names are held in memory and cleared when Chrome closes.
  • No remote code. Everything runs from files in the package.
